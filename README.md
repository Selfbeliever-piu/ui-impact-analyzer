# UI Impact Analyzer

A Node.js + TypeScript tool for analyzing UI-related changes and their potential impact.
This project is in its early stage and is designed as a foundation for building developer
tooling and automation around UI change analysis.

---

## 🚀 Features

- Node.js–based execution
- Written in TypeScript with strict configuration
- Modern ESM setup (`NodeNext`)
- Clean, minimal, and extensible architecture

---

## 🛠 Tech Stack

- Node.js
- TypeScript
- ts-node
- ECMAScript Modules (ESM)
